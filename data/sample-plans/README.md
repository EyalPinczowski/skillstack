# Sample plans

`demo-plan.json` is a **fictional** "Junior Data Analyst" plan in the shared plan-file format (`formatVersion` 1, see `packages/shared/src/schemas.ts`). It contains no personal data. Course titles, providers and links come from `data/catalog/catalog.json`; items whose link or price is not verified have no `url` and carry a "needs check" note. It is used by tests (`packages/shared/src/sample-plan.test.ts`), the R&D environment and the demo.
